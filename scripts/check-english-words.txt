# German words that check-english.ps1 looks for, one per line, matched as whole
# words and case-insensitively. Lines starting with # are comments.
#
# This is the only file the check excludes from its own scan - it consists of
# German words by definition. Everything else, including check-english.ps1
# itself and check-english-ignore.txt, is scanned like any other file.
#
# Selection rule: a word belongs here only if it is neither an English word nor
# a Pascal keyword nor a plausible identifier. "die" and "fall" are deliberately
# absent - both are English. Prefer adding a word that actually occurs in this
# repository over completing a grammar. Words of three or four letters are
# risky in this codebase: the encoders carry tables of short string literals.
# "also" (English) and "als" (matches a PDF417 table entry) were removed for
# exactly that reason.
#
# The list cannot be complete. A German sentence made only of words that are not
# listed will pass. The script is a safety net against overlooking a whole file,
# not proof that a file is English.
